# Daily Stock Analysis AI Agent Repository

## Verified Features

`ZhuLinsen/daily_stock_analysis` สร้างรายงานหุ้นตาม watchlist เป็น dashboard พร้อมข้อสรุป คะแนน แนวโน้ม ระดับเข้า/ออก ความเสี่ยง catalyst และ checklist แล้วส่งผ่าน Telegram, Discord, Slack, Email, WeChat Work หรือ Feishu รองรับตลาดจีน ฮ่องกง และสหรัฐตาม README

## Claim Audit

ตัวเลข stars, forks, global rank และคำว่า “ฟรีทั้งหมด” ในโพสต์เป็นข้อมูลเวลาเฉพาะและอาจเปลี่ยนได้ การรัน GitHub Actions อาจไม่มีค่า compute ภายใต้ quota แต่ data/API/LLM บางตัวมีค่าใช้จ่ายหรือข้อจำกัด เครื่องมือนี้สร้าง decision support ไม่ใช่ Bloomberg Terminal ทดแทนและไม่ใช่คำแนะนำการลงทุน
