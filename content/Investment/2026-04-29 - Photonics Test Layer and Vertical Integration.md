# Photonics Test Layer และ Vertical Integration

> [!summary] TL;DR
> โพสต์มอง test & qualification เป็น pick-and-shovel ของ optical value chain และจำแนกบริษัทตามชั้นที่ควบคุม เพื่อประเมินว่า vertical integration อยู่ตรง bottleneck ที่มีมูลค่าหรือกลายเป็นต้นทุนคงที่ที่หนักเกินไป

## Key Takeaways

- ความเร็ว 400G → 800G → 1.6T และ CPO ทำให้ wafer-level test, burn-in และ thermal/load qualification สำคัญขึ้น
- รูปแบบ integration ที่เสนอมี upstream, downstream, materials-devices, IC-laser, middle และ specialty integration
- Moat ไม่ได้เกิดจากจำนวน layer อย่างเดียว แต่เกิดเมื่อการรวมช่วยคุม supply bottleneck, yield, performance หรือ time-to-market

## Due-Diligence Caveat

การจัดบริษัทลงแต่ละ layer และข้อกล่าวเรื่อง EML/laser shortage เป็นมุมมองของผู้เขียน ณ เวลานั้น โพสต์ไม่มี filing หรือ segment data รองรับครบทุกบริษัท ก่อนลงทุนต้องตรวจ 10-K/20-F, earnings calls, supplier concentration, capex, yield และสัดส่วนรายได้จริง
