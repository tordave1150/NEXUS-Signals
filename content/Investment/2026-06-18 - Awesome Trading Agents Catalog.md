# Awesome Trading Agents Catalog

## What It Is

Curated list ของ LLM-driven trading agents, MCP servers, agent skills, benchmarks และแหล่งเรียนรู้ ครอบคลุม research copilots, multi-agent systems, market data, broker/exchange execution, backtesting และ portfolio workflows

## Verification & Safety

Repository ทางการยืนยันหมวด Agents, MCPs, Skills และ Resources พร้อมสัญญาอนุญาต CC0-1.0 การถูกลิสต์ไม่ใช่ security audit หรือการรับรองผลตอบแทน โดยเฉพาะ tools ที่เข้าถึง live trading ต้องตรวจ maintainer, permissions, secret handling, order confirmation, paper mode, position limits, logs และ kill switch ก่อนเชื่อมบัญชีจริง
