# Investbrain Self-Hosted Portfolio Platform

## Verified Features

Investbrain เป็นเว็บแอปโอเพนซอร์สสำหรับติดตามพอร์ตแบบ self-hosted รองรับผู้ให้บริการข้อมูล Yahoo Finance, Twelve Data, Finnhub, Alpaca และ Alpha Vantage พร้อม fallback ตามลำดับที่ตั้งค่าไว้ มี import/export ธุรกรรมและพอร์ต รวมถึง AI chat ที่เชื่อมผู้ให้บริการหลายรายหรือ Ollama ผ่าน API ที่เข้ากันได้

## Operational Notes

README แนะนำ Docker Compose และผู้ใช้ต้องดูแล API keys, การอัปเดต, backup และความปลอดภัยเอง ความพร้อมของข้อมูลยังขึ้นกับ quota คุณภาพ และเงื่อนไขของผู้ให้บริการภายนอก ส่วน AI chat เป็นเครื่องมือช่วยคิด ไม่ใช่ผู้แนะนำการลงทุน
