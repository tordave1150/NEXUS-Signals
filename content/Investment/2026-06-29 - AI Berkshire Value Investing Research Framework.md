# AI Berkshire Value Investing Research Framework

## What It Is

AI Berkshire เป็นชุด skills และ workflows สำหรับทำวิจัยการลงทุนเชิง value investing ด้วย Claude Code หรือ Codex มีทั้งการวิเคราะห์งบ ธุรกิจ ผู้บริหาร ความเสี่ยง และการสังเคราะห์มุมมองหลาย agent

## Verified Features

README ต้นทางยืนยันความเข้ากันได้กับ Claude Code/Codex, โครงสร้าง multi-agent, เครื่องมือตรวจตัวเลขด้วย decimal และการ cross-validation แหล่งข้อมูล อย่างไรก็ตามผลตอบแทนที่ repository อ้างเป็นข้อมูลจากผู้ดูแลโครงการ ไม่ใช่หลักฐานอิสระ และอดีตไม่รับประกันผลในอนาคต
