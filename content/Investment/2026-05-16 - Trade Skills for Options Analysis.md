# Trade Skills for Options Analysis

> [!summary] TL;DR
> `himself65/trade-skills` เป็น open-source skill/plugin สำหรับช่วยจัดกรอบวิเคราะห์ multi-leg options, IV, probability-weighted scenarios, pitfalls และ case studies ไม่ใช่ระบบส่งคำสั่งซื้อขายหรือคำแนะนำการลงทุน

## Verification & Caveat

README ปัจจุบันยืนยันคำสั่งติดตั้ง `npx skills add himself65/trade-skills` และระบุ 25 pitfalls/case studies มากกว่าตัวเลข 15 ในโพสต์ แสดงว่า repository เปลี่ยนหลังเผยแพร่ การใช้จริงควร pin commit, ตรวจ license/dependencies และทวนราคา/Greeks กับข้อมูลตลาดก่อนตัดสินใจ
