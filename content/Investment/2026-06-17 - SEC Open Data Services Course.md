# SEC Open Data Services Course

## Why I Saved This

หลักสูตรทางการฟรีสำหรับสร้าง data pipeline จากข้อมูลตลาดทุนไทย เหมาะกับงาน research, dashboard และ fund analysis ที่ต้องการแหล่งข้อมูล traceable กว่าการ scrape หน้าเว็บ

## Five Modules

1. Getting Started with SEC Open Data Services — 10.28 นาที
2. Business Understanding ผ่านกรณีศึกษากองทุนรวม — 12.32 นาที
3. Data Collection จาก SEC Open APIs — 16.11 นาที
4. Data Cleansing, health checks, missing/duplicate data และ integration — 25.23 นาที
5. EDA และ visual analysis ของข้อมูลกองทุน — 17.12 นาที

รวมเวลาที่หน้า course แสดงประมาณ 81 นาที สอดคล้องกับโพสต์ที่ระบุราว 80–90 นาที

## Verification & Caveat

หน้า SEC E-Learning ทางการยืนยันชื่อ course และห้าโมดูล แต่ availability, certificate rules, API schema, rate limits และ endpoints อาจเปลี่ยนได้ ควรบันทึก retrieval date, raw response, schema version และ validation tests ใน pipeline จริง
