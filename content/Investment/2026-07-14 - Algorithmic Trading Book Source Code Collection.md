# Algorithmic Trading Book Source Code Collection

## Summary

Repository `zslucky/algorithmic_trading_book` เก็บ PDF และ source code ประกอบหนังสือ *Successful Algorithmic Trading* กับ *Advanced Algorithmic Trading* โฟลเดอร์ `sat_source` แบ่ง code ตามบท 7-16 พร้อม requirements และตัวอย่างใช้งาน

## Caveat

เป็น code การศึกษาและอาจใช้ library/API รุ่นเก่า ควรตรวจ license, dependency versions, data assumptions และแก้ execution/cost model ก่อนนำไปใช้กับตลาดจริง การมี backtest code ไม่รับรอง reproducibility หากไม่มีข้อมูลและ environment เดียวกัน
