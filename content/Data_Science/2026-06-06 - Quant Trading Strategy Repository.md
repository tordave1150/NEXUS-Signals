# Quant Trading Strategy Repository

> [!summary] TL;DR
> คลังตัวอย่าง Python สำหรับศึกษากลยุทธ์และเครื่องมือ quant หลายแนว ตั้งแต่ VIX, pairs trading, Monte Carlo และ options straddle ไปจนถึง RSI, Bollinger Bands, Parabolic SAR และ MACD

## Practical Use

เหมาะสำหรับอ่านโค้ดเป็นกรณีศึกษา เปรียบเทียบวิธีคำนวณ indicator และสร้างต้นแบบเร็ว แต่แต่ละ notebook/script ใช้แหล่งข้อมูล ช่วงเวลา และสมมติฐานต่างกัน จึงไม่ใช่ framework production แบบรวมศูนย์

## Verification & Caveat

Repository ทางการยืนยันรายการกลยุทธ์ที่โพสต์กล่าวถึง ก่อนนำผลไปใช้ควรตรวจ dependency และ API ที่อาจเก่า, corporate actions, look-ahead/survivorship bias, transaction costs, slippage, parameter selection และ out-of-sample validation ทุกตัวอย่าง การมีโค้ดรันได้ไม่เท่ากับมีกลยุทธ์ที่ทำกำไรได้จริง
