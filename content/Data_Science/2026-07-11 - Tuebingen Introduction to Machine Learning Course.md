# Tuebingen Introduction to Machine Learning Course

## Summary

คอร์ส Machine Learning I ของ Dmitry Kobak จาก University of Tübingen ปูตั้งแต่ linear/multiple regression, likelihood, bias-variance, regularization และ cross-validation ไปจนถึง classification, ensembles, PCA, manifold learning และ t-SNE วิดีโอเป็น lecture ช่วง Winter Term 2020/21 บนช่อง Tübingen Machine Learning

## Learning Path

เหมาะกับผู้เรียนที่มี calculus, linear algebra และ probability พื้นฐาน ควรทำแบบฝึกหัดและทดลองด้วยข้อมูลจริงควบคู่ เพราะการดู lecture อย่างเดียวไม่สร้างทักษะ model diagnosis หรือ validation
