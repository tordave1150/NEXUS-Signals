# Build Your Own Machine Learning

## Why I Saved This

Repository นี้เป็นแผนที่เรียน Machine Learning แบบลงมือสร้างองค์ประกอบเอง เหมาะสำหรับเปลี่ยนความรู้ที่จำจาก API ให้เป็นความเข้าใจกลไกและข้อสมมติของอัลกอริทึม

## Key Takeaways

- รวม tutorial ตั้งแต่ linear/logistic regression, KNN, trees, clustering และ optimization
- ขยายไป neural networks, deep learning, recommendation, computer vision, NLP, forecasting, anomaly detection และ LLMs
- หลายบทเน้น NumPy และการ implement from scratch ก่อนใช้ framework สำเร็จรูป
- โครงการใช้ Apache-2.0 และระบุว่าจะอัปเดตรายการ tutorial ต่อเนื่อง
