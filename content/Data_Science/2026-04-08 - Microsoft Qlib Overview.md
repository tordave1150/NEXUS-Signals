# Microsoft Qlib - AI-Oriented Quant Platform

> [!summary] TL;DR
> Qlib เป็นแพลตฟอร์มโอเพนซอร์สสำหรับ quant research ครอบคลุม data processing, model training, backtesting, risk/portfolio analysis, execution และ online serving

## Verification & Reconciliation

Repository ทางการของ Microsoft ยืนยันคำอธิบายหลัก รวมทั้ง supervised learning, market-dynamics modeling, reinforcement learning, automated workflows และ online model rolling อย่างไรก็ตาม “from idea to production” หมายถึง framework capability ไม่ใช่ production readiness อัตโนมัติ ผู้ใช้ยังต้องจัดการ point-in-time data, leakage, costs, deployment controls และ monitoring
