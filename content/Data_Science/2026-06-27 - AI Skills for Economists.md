# AI Skills for Economists

## What It Is

`awesome-econ-ai-stuff` เป็น curated collection ของ AI skills สำหรับนักเศรษฐศาสตร์ โดยใช้มาตรฐาน `SKILL.md` และระบุ compatibility กับ Claude Code, Cursor, Codex, Gemini CLI และเครื่องมือ AI-native อื่น

## Value and Limits

Skills สามารถทำให้ workflow การค้นข้อมูล วิเคราะห์ และจัดทำงานวิจัยทำซ้ำได้มากขึ้น แต่ repository เป็นชุด instruction ไม่ใช่หลักฐานว่าผลวิเคราะห์ถูกต้อง ต้องตรวจ identification assumptions, source provenance, code, units, sample construction และ reproducibility ของแต่ละ skill รวมถึงระวังข้อมูลเศรษฐกิจที่ถูก revise

## Verification

README ทางการยืนยันมาตรฐานและแพลตฟอร์มที่รองรับ พร้อม template/contribution workflow โพสต์เรียกว่า “ระบบอัตโนมัติ” ซึ่งกว้างเกินไป: ระดับ automation จริงขึ้นกับ skill, tools, credentials และ approval boundaries ของผู้ใช้
