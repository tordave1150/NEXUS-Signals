# ML System Design Case Studies Collection

## Summary

Repository รวบรวมกรณีศึกษาระบบ ML ในงานจริงมากกว่า 300 รายการจากกว่า 80 บริษัท เช่น Netflix, Airbnb และ DoorDash จัดหมวดตามอุตสาหกรรมและ use case เหมาะสำหรับเทียบ architecture, retrieval/ranking, experimentation, monitoring และ operational constraints

## Use Method

ใช้เป็น index ไปยังบทความต้นฉบับของแต่ละบริษัท ไม่ควรถือคำอธิบายสั้นในรายการเป็นหลักฐานสมบูรณ์ จำนวนรายการอาจเปลี่ยนตามการอัปเดต repository
