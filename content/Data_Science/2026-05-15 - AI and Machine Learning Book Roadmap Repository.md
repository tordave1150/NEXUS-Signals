# Repository แผนอ่านหนังสือ AI และ Machine Learning

> [!summary] TL;DR
> โพสต์แนะนำ repository ที่จัดหนังสือมากกว่า 30 เล่มตามระดับ beginner, intermediate และ advanced ครอบคลุม Python/data analysis, model building, deep learning, statistics และ production AI systems

## Suggested Use

ใช้รายการเป็น syllabus map: เริ่ม Python/data foundations ต่อด้วย statistical learning/modeling และจบที่ ML systems/AI engineering พร้อมเลือกหนังสือตามช่องว่าง ไม่จำเป็นต้องอ่านทุกเล่มตามลำดับ

## Limitation

ลิงก์ repository ไม่ปรากฏในข้อความที่เข้าถึง จึงยังตรวจรายการ ความถูกต้องของระดับ หรือว่าลิงก์ชี้ไปยังตัวอย่าง/หนังสือที่เผยแพร่โดยชอบด้วยลิขสิทธิ์ไม่ได้ ควรใช้เฉพาะ publisher/author pages หรือสำเนาที่ได้รับอนุญาต
